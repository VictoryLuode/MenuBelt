Custom Modular Menu (CMM)

Build your own multi-list action menus and reach them from three places at once: the cursor, the Tools menu, and a dockable panel.

Features

  • Multiple lists — e.g. "Canvas Assist", "Layers", "Add Layer", "View". Every list is fully yours to build.
  • Reuses native Krita actions — each item is a real Krita action, so icons, enable/disable state and shortcut hints are inherited automatically.
  • Script items — run your own Python snippet from a menu item (Krita is available as krita/app).
  • Live preview — a pane in the editor shows the whole menu tree as you edit.
  • Export / Import — save or load a config file to share or back up your setup.
  • Shortcut conflict detection — warns if a list shortcut collides with another list or a Krita action.
  • Enable / disable a menu — tick the checkbox next to a list in the Menu List to activate it, untick to hide it (skipped in the cursor popup, the Tools submenu and its shortcut; still editable so you can re-enable it).
  • List or Pie form — each menu can open as a linear List or a Blender-style Pie (radial): hold the shortcut, drag toward a direction, release to activate. Pie supports up to 8 items (submenus are not shown in a pie).
  • Nested submenus — add a menu inside a menu (any depth), each holding its own commands and further submenus, for modular organisation.
  • Custom names — rename any item to whatever you like; the menu and Tools submenu show your name (with the native icon and behaviour).
  • Two synced entries: a cursor popup menu, and Tools > Custom Modular Menu.
  • Configurable shortcuts — bind a hotkey for the whole menu or per list, right inside the editor (no need for Krita's Keyboard Shortcuts dialog).

Install / enable

  1. Copy the pykrita/ and actions/ folders into your Krita resource directory, then restart Krita.
  2. In Settings > Configure Krita > Python Plugin Manager, tick Custom Modular Menu, then restart.

Usage

  • Add items: the Add items pane picks what to insert — Krita Actions (grouped by Krita’s own shortcut-editor categories via a second dropdown) or Layer Blend Mode.
  • Custom names: in the editor, double-click a command item to give it a custom name; leave empty to use Krita’s default.
  • Submenus: press Add Submenu to nest a menu, then double-click it to enter; use the breadcrumb at the top to go back. Dragging reorders items (and submenus) anywhere.
  • Scripts: press Add Script, give it a name and paste Python code; clicking the item runs it.
  • Layer blend mode: in the Add items pane switch to Layer Blend Mode and add one — clicking it sets the active layer blend mode (via Node.setBlendingMode). This is the layer’s blend mode, not the brush’s.
  • Shortcuts: in the editor, click the Shortcut field and press a key combination (e.g. Ctrl+Alt+1) to pop that list at the cursor. The whole-menu popup is bound in Settings > Configure Krita > Keyboard Shortcuts > Custom Modular Menu > Pop Up Custom List.
  • Docker panel: removed in this version (not needed).
Tip: prefer modifier+key combos (Ctrl/Alt/Shift + a key) and avoid shortcuts already used by Krita actions, or they won't fire.

Technical notes

  • Shortcuts use an app-level key event filter (not QShortcut), which is reliable inside Krita.
  • The action catalog is enumerated at runtime with Krita.instance().actions(), so you can pick any action.
  • Your list configuration is stored in config.json inside the plugin folder (not tracked by git).
